# Philosophy

This framework is low-control and high-accountability.

It should not try to outguess a future model by encoding a rigid mathematical
strategy. Instead, it should make research state legible:

- assumptions are explicit,
- claims have status,
- experiments are reproducible,
- failures are preserved,
- tools are described,
- reports separate proof from evidence.

The framework is successful when a later human or AI collaborator can inspect
the repository and understand what is known, what is conjectural, what failed,
and what should happen next.
